# Skillbase

Manage Agent Skills across every coding agent on your machine.

Skills live in one place. Each agent gets a link into it. Which agents can see a
skill is a setting, not a directory you maintain by hand.

## Status

Early. See `docs/PLAN.md` and `docs/SPEC.md`.

## Build

```sh
cargo run
```

Requires Rust 1.98 or newer.
